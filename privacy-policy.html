JapanHub 개인정보처리방침

시행일: 2026년 9월 13일

JapanHub(이하 “앱”)는 Android 및 iOS 기기의 앱 내부 브라우저에서 재생하거나 사용자가 녹음한 영상 음성을 일본어 자막과 번역문으로 처리하는 기능을 제공합니다. 이 방침은 앱이 처리하는 정보와 사용자가 이를 삭제하는 방법을 설명합니다.

1. 처리하는 정보

  • 오디오: 사용자가 실시간 번역 또는 녹음 후 번역을 시작한 경우 필요한 오디오 구간을 처리합니다. Android는 사용자가 승인한 화면·재생 오디오 캡처를 사용하고, iOS는 사용자가 허용한 마이크 입력을 사용하므로 주변 소리가 함께 포함될 수 있습니다.
  • 인식·번역 텍스트: 음성 인식 결과와 번역 결과가 자막 표시 및 저장 자막 기능에 사용될 수 있습니다.
  • 사용자가 입력한 설정: Gemini API 키, 번역 언어, 번역 설정, 첫 페이지, 북마크와 같은 설정이 기기에 저장될 수 있습니다.
  • WebView 사이트 데이터: 사용자가 방문한 사이트의 쿠키, 캐시, DOM Storage 등은 운영체제의 WebView 정책에 따라 기기에 저장될 수 있습니다.

2. 처리 목적과 처리 방법

앱은 자막 생성과 번역이라는 요청된 기능을 제공하기 위해 오디오 또는 인식된 텍스트를 Google Gemini API에 전송할 수 있습니다. 요청은 generativelanguage.googleapis.com의 Gemini 서비스로 전송되며, 전송 시 사용자가 등록한 API 키가 인증에 사용됩니다.

번역 모드에 따라 오디오가 Gemini로 전송되거나, 기기에서 인식된 일본어 텍스트만 번역을 위해 전송될 수 있습니다. 네트워크 연결, Gemini의 보존·처리 정책, API 프로젝트의 쿼터와 요금제가 적용될 수 있습니다.

3. 제3자 서비스와 비용

Gemini API를 사용하려면 네트워크 연결과 사용자가 등록한 API 키가 필요합니다. API 제공자의 쿼터, 보존 및 처리 정책이 적용될 수 있으며, API 프로젝트의 요금제에 따라 비용이 발생할 수 있습니다. API 키는 앱에 직접 입력할 수 있으므로 다른 사람과 공유하지 마십시오. 앱 또는 APK에 키를 저장하는 방식은 키의 완전한 비밀성을 보장하지 않습니다.

앱은 별도의 광고·분석 SDK를 통해 음성, 자막 또는 WebView 데이터를 전송하도록 설계되어 있지 않습니다. 방문하는 웹사이트는 자체 개인정보처리방침과 저장 기술을 적용할 수 있습니다.

4. 기기 내 저장과 삭제

자막 이력, 세션 메타데이터, 번역 결과, 토큰 사용 통계, 북마크와 설정은 앱의 로컬 저장소에 저장될 수 있습니다. 녹음 후 번역을 사용하는 경우 처리에 필요한 WAV/PCM 파일이 처리 완료 전후에 기기에 남을 수 있습니다.

저장 자막·세션은 앱에서 제공하는 기록 삭제 기능으로 삭제할 수 있으며, 앱 데이터 삭제 또는 앱 제거로 앱의 로컬 데이터를 삭제할 수 있습니다. 브라우저 메뉴의 “사이트 데이터 삭제”는 WebView 탭의 캐시, 방문 기록, 쿠키, DOM Storage 및 Web Storage를 대상으로 하며 저장 자막·즐겨찾기·앱 설정·앱 데이터베이스까지 삭제하지는 않습니다.

5. 권한

Android에서는 기능에 필요한 경우 오디오 재생 캡처, MediaProjection, 알림 및 다른 앱 위에 표시 권한을 요청합니다. iOS에서는 기능에 필요한 경우 마이크 권한을 요청합니다. 연락처·위치 권한은 기능에 사용하지 않습니다. 사용자는 운영체제 설정에서 권한을 거부하거나 변경할 수 있으며, 권한을 거부하면 관련 기능이 동작하지 않을 수 있습니다.

6. 광고 및 분석

앱은 별도의 광고 SDK 또는 분석 SDK를 통해 오디오, 자막, WebView 데이터 및 사용 기록을 전송하도록 설계되어 있지 않습니다. 사용자가 방문하는 웹사이트는 자체 개인정보처리방침과 저장 기술을 적용할 수 있습니다.

7. 방침 변경

앱의 기능이나 관련 법령이 변경되면 이 방침을 수정할 수 있습니다. 변경된 방침은 이 페이지에 시행일과 함께 게시합니다.

8. 문의

개인정보 관련 문의는 Google Play 또는 App Store에 표시된 JapanHub 개발자 연락처를 이용해 주십시오.

이 문서는 JapanHub의 현재 Android 및 iOS 구현과 앱 설명을 기준으로 작성되었습니다. Google Gemini 서비스의 상세한 데이터 처리 방식은 Google의 관련 약관과 개인정보처리방침도 함께 확인해 주십시오.
